🍳 Interactive Recipe Finder








Smart, ingredient-based recipe suggestions to reduce food waste and make meal planning effortless.

📖 Overview

The Interactive Recipe Finder is a lightweight web application that helps users discover recipes based on ingredients they already have.
It encourages creativity in cooking, reduces food waste, and makes meal planning quick and fun.

✨ Features

🥕 Ingredient Input System – Add, remove, clear, and auto-suggest ingredients

🍲 Smart Recipe Search – Algorithm with match percentages & relevance sorting

🖼 Recipe Cards – Responsive grid with cooking time, difficulty & preview

📖 Detailed Recipe Modal – Instructions, nutrition, and source links

⭐ Favorites – Save recipes with LocalStorage persistence

🔄 Sharing – Share recipes directly via social media

📱 Responsive UX – Mobile-first design, smooth animations, error handling

🥗 Advanced Filters – Dietary preferences (vegan, vegetarian, gluten-free) + meal types

⏲ Extras – Cooking timer, print option, cost estimate, categorization

⚡ Getting Started
🔑 Prerequisites

Latest version of Chrome, Firefox, or Edge

📥 Installation
git clone <https://github.com/KondamPravalikaReddy/Interactive-Recipe-Finder>

cd recipe-finder

▶️ Run Locally

Open directly:

index.html


Or serve with a local server:

npx serve .
# or
python -m http.server


🔧 Customization

🔗 API Integration – Connect to Spoonacular or Edamam (edit app.js)

🍴 Recipe Expansion – Add or update mock recipes in app.js

🎨 UI Updates – Customize CSS for branding or themes
